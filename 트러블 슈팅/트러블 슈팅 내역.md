# 트러블 슈팅 내역

## 1. 우분투 실행 오류

- 에러코드 0x80370114

### 처리 과정

1. wsl 설치상태 확인

- PowerShell(관리자 권한) 실행 후 다음 두 명령어 실행 후 결과 확인
```bash
wsl --status		// WSL 설정 상태 확인
wsl --list --verbose	// WSL 버전 확인
```

실행 결과 : WSL2 실행용 필수 기능이 활성화되지 않은 상태

![실행 결과](<../트러블 슈팅/트러블슈팅 이미지/이미지 1-1.png>)

2. Window 기능 활성화

- PowerShell(관리자 권한) 실행 상태에서 다음 두 명령어 실행 후 재부팅
``` bash
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
// Windows Subsystem for Linux 활성화
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
// Virtual Machine Platform 활성화
```

- 재부팅 후 설정 상태 확인 명령어 재입력 후 결과 확인
`wsl --status`

결과 : 기능관련 오류메세지 제거 성공
![실행 결과](<../트러블 슈팅/트러블슈팅 이미지/이미지 1-2.png>)

- Ubuntu 설치 상태 확인
`wsl --list --verbose`

결과 : 설치된 배포판 없음
![실행 결과](<../트러블 슈팅/트러블슈팅 이미지/이미지 1-3.png>)

- Ubuntu 설치
`wsl --install -d Ubuntu`

- Username 및 Password 설정 : user/3073
![실행 결과](<../트러블 슈팅/트러블슈팅 이미지/이미지 1-4.png>)

## 2. Docker 실행 오류

- Docker 명령어가 Ubuntu 터미널에서 실행되지 않음

```bash
docker --version
```

![실행 결과](<../트러블 슈팅/트러블슈팅 이미지/이미지 2-1.png>)

### 처리 과정

1. 오류 메시지 확인

- 상단 이미지

- 상태
- - Ubuntu 환경에서 Docker 명령어를 찾을 수 없음.
- - Docker Desktop및 WSL2는 정상 실행되는 상황.
- - WSL-Docker 통합 및 Docker Engine 연결 과정을 거치지 않은 상황이니 이 두곳 중 하나가 유력함.

2. WSL Integration 활성화

- Docker Desktop의 설정 진입
- classic settings로 진입 후 Resources 탭으로 진입
- WSL Integration 선택 후 Ubuntu 활성화
- 설정 후 Apply and restart

![실행 결과](<../트러블 슈팅/트러블슈팅 이미지/이미지 2-2.png>)

3. 검증

- Ubuntu 접속 후 명령어 재실행

```bash
docker --version
```

![실행 결과](<../트러블 슈팅/트러블슈팅 이미지/이미지 2-3.png>)

-정상실행확인
